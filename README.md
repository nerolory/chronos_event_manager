# Chronos Event Manager

Комплексная система управления событиями с кинетическим отображением часов, интерактивным календарем и возможностями пакетного программирования.

![Chronos Event Manager](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-Apache%202.0-green.svg)

## Описание

Chronos Event Manager — это современное веб-приложение, предназначенное для эффективной организации и управления событиями. Проект демонстрирует различные задачи программирования и современные паттерны веб-разработки.

### Основные возможности

- **Кинетический движок часов**: Анимированное отображение времени с использованием кинетической типографики с сеткой 28x8 отдельных циферблатов, формирующих цифры
- **Интерактивный календарь**: Полнофункциональный календарь с планированием событий методом drag-and-drop, поддержкой многодневных событий и повторяющихся событий
- **Пакетные операции**: Инструменты для выполнения массовых операций над событиями, включая создание, редактирование и удаление
- **Современный интерфейс**: Чистый, адаптивный интерфейс, созданный с использованием Vue 3, Tailwind CSS и методологии БЭМ

## О проекте

Этот проект демонстрирует решение различных задач программирования:

1. **Кинетическая типографика**: Сложные анимации с использованием CSS-трансформаций и JavaScript для создания динамического отображения часов
2. **Системы календаря**: Продвинутая работа с датами, классификация событий и визуальное представление
3. **Пакетное программирование**: Эффективная обработка массовых операций с сохранением целостности данных
4. **Современная архитектура**: Чистые паттерны кода с Vue 3 Composition API, Pinia для управления состоянием и разделением ответственности

## Установка

### Быстрый старт с Docker

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/chronos-event-manager.git
cd chronos-event-manager

# Запуск инфраструктуры
docker-compose up -d --build

# Установка зависимостей
docker exec -it chronos_app composer install
docker exec -it chronos_app npm install

# Применение миграций базы данных
docker exec -it chronos_app php artisan migrate

# Сборка фронтенд-ассетов
docker exec -it chronos_app npm run build

# Настройка прав доступа
docker exec -it chronos_app chown -R www-data:www-data storage bootstrap/cache
```

## Технологический стек

### Frontend
- **Vue 3** - Прогрессивный JavaScript-фреймворк с Composition API
- **Pinia** - Управление состоянием
- **Tailwind CSS** - CSS-фреймворк с утилитарными классами
- **Vite** - Инструмент сборки и сервер разработки
- **SCSS** - CSS-препроцессор

### Backend
- **PHP 8.1+** - Серверный язык программирования
- **Laravel** - PHP-фреймворк
- **MySQL/PostgreSQL** - База данных

### Инструменты разработки
- **ESLint** - Линтинг JavaScript/Vue
- **Stylelint** - Линтинг CSS/SCSS
- **Docker** - Контейнеризация
- **Composer** - Управление зависимостями PHP
- **npm** - Управление пакетами JavaScript

## Качество кода

Проект следует строгим стандартам качества кода:

- **Паттерны ES6+**: Современные возможности JavaScript (стрелочные функции, деструктуризация, шаблонные строки)

- **Линтинг**: Автоматизированные проверки качества кода с ESLint и Stylelint

## Возможности подробно

### Кинетические часы
- Отображение времени в реальном времени с анимацией
- Сетка 28x8 отдельных циферблатов
- Плавные анимации с cubic-bezier
- Поддержка нескольких часовых поясов
- Градиентные эффекты и стилизация с объемом
- Стилизация border-часов с табличным видом

### Календарь
- Месячный, недельный и дневной виды
- Планирование событий методом drag-and-drop
- Поддержка многодневных событий с визуальными индикаторами
- Цветовая кодировка событий с автоматическим контрастом текста
- Выделение выходных и праздничных дней
- Повторяющиеся события (ежедневные, еженедельные, ежемесячные)

### Управление событиями
- Создание, редактирование и удаление событий
- Категоризация событий с пользовательскими цветами
- Планирование с учетом часовых поясов
- Сохранение длительности события при drag-and-drop
- Поддержка пакетных операций
